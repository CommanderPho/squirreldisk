2. Chart Style — NOT an Enum, Just a String

The chart style is stored as a plain String in Settings, NOT an enum:

Default value (line 88):

There are exactly two chart styles: "sunburst" and "treemap".

The selection UI is in src/ui/modals.rs (lines 347-359) — a simple loop over two hard-coded string values:

rust
for (k, (value, label)) in [("sunburst", tr("Sunburst")), ("treemap", tr("Treemap"))].into_iter().enumerate() {

    if widgets::button(ui, r, Id::new(("chart-style", k)), label, None, style, &theme).clicked() {
        s.chart_style = value.to_string();

}

It can also be overridden via env var SQUIRRELDISK_CHART at startup (src/ui/app.rs line 459-461).

4. The Rendering Pipeline
Sunburst Rendering Pipeline:
Layout → sunburst::layout() in src/ui/sunburst.rs line 119 — computes Vec<Seg> (angular sectors by DFS traversal of the tree)
Animation → Animator::set_target() / Animator::step() in src/ui/sunburst.rs lines 227/275 — keyed morphing of segments (angles, depth, color, alpha)
Vertex Generation → sunburst::build_vertices() in src/ui/sunburst.rs line 356 — tessellates annular sectors into triangle lists (14 floats per vertex: pos, color, polar coords, params)
GPU Rendering → SunburstGl::paint() in src/ui/shader.rs line 199 — custom OpenGL shader with AA gaps, hover tint, collector hatch
CPU Fallback → cpu_mesh() function in src/ui/view.rs (for systems without GL)

The sunburst uses custom OpenGL shaders (GLSL vertex+fragment) in src/ui/shader.rs:

Vertex shader: transforms positions to screen space, passes varyings
Fragment shader: analytic anti-aliased gaps between segments, edge rim, hover tint, collector hatching, drag ghost dimming
Treemap Rendering Pipeline:
Layout → treemap::layout() in src/ui/treemap.rs line 94 — squarified treemap (Bruls/Huizing/van Wijk algorithm), produces Vec<Tile>
Animation → TreemapState::set_target() / TreemapState::step() — rect/color lerping
Drawing → treemap_ui() in src/ui/treemap.rs line 308 — uses egui's immediate-mode painter (p.rect_filled(), p.text(), p.line_segment()) — NO custom shaders, pure CPU/egui drawing

6. The Data Model — Tree (src/tree.rs)

Arena-based file tree:

rust
pub struct Tree {
    pub nodes: Vec<Node>,
    pub root: u32,
    pub version: u64,     // incremented on mutation for cache invalidation
    pub root_path: String,
    pub sep: char,
    pub source: Source,    // Local, Ssh, Rclone, Demo
}
pub struct Node {
    pub name: Box<str>,
    pub size: u64,         // allocated bytes of whole subtree
    pub files: u32,        // file count in subtree
    pub parent: u32,
    pub first_child: u32,
    pub next_sibling: u32,
    pub kind: Kind,        // Dir, File, SmallFiles, Link, Mount, Hidden
    pub flags: u8,         // F_DONE, F_DENIED, F_DETACHED, F_EXPANDABLE
}

The tree is shared as SharedTree = Arc<RwLock<Tree>> (defined in scan module). Key methods: sorted_children(), can_enter(), path(), is_alive(), ancestry().

7. Theme/Color System (src/ui/theme.rs)

7 built-in themes (Hazelnut, Midnight Neon, Autumn Forest, Dracula, Nordic, Sunset, Paper). Each has a wheel — a cyclic color gradient array used for segment coloring by angular position.

Key methods:

theme.segment_color(mid, depth, is_file) — color from wheel position + depth lightening
theme.aggregate_color() — for "smaller items" groups
theme.wheel_at(t) — sample the cyclic gradient
8. Session State (src/ui/app.rs line 47)

Each scan session holds:

tree: SharedTree — the file tree
view: View — current center node
anim: Animator — sunburst animation state
treemap: TreemapState — treemap animation state
geo: Option<Geometry> — sunburst geometry
collector: Vec<u32> — nodes collected for deletion
Navigation history (back, fwd)
9. 3D Rendering Utilities — NONE

No 3D rendering code exists. The only GPU code is the 2D OpenGL shader in src/ui/shader.rs for the sunburst, which renders flat 2D annular sectors with gl_Position.z = 0.0. The treemap uses pure egui 2D painting.
